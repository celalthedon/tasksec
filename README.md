# SafeNotes Coursework Project

## Overview
SafeNotes is a frontend-only educational web application for a cybersecurity assignment: **"Build, Break, and Secure a Web Application."**

The project includes:
- a **vulnerable** version with intentionally insecure patterns
- a **secured** version with safer frontend practices and clear limitations of client-only security

## How to Run Locally
1. Open this project folder on your machine.
2. Open either version directly in a browser:
   - Vulnerable: `vulnerable/index.html`
   - Secured: `secured/index.html`
3. No server or backend is required.

## Which Version is Which?
- `vulnerable/` → intentionally insecure for demonstration and exploitation steps.
- `secured/` → improved frontend implementation focused on safer coding patterns and clear security boundaries.
